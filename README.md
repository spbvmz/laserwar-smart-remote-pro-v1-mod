# Laserwar Умный пульт Про V.1 — модификация прошивки

[English version](README.en.md)

Неофициальная модификация прошивки v1.14 для пульта Laserwar «Умный пульт Про V.1» (Smart PRO Remote) для лазертага. В главное меню добавляется раздел «Девайсы»: с пульта можно настраивать точку захвата, умную аптечку 2.0, умного медика и командный пункт без компьютера и конфигуратора.

Текущая версия мода: **1.04** (27.10.2026), основа — официальная прошивка **v1.14**.

## Что добавлено

- **INFO** — версия мода и контакты.
- **Настройка** — сценарий точки (Захват точки, Battlefield, Пункт управления), задержка старта, язык звуков.
- **Точка** — все параметры режимов «Захват точки», «Точка Battlefield» и «Пункт управления», команды отрицательного и положительного импульса (63 ИК-команды).
- **Умная аптечка 2.0** — комплекты, время удержания, попадания, игровой режим (Здоровье, Боезапас, Энергия с периодом и активацией), время раунда, команды для каждого режима, длительность излучения.
- **Умный медик** — комплекты, время срабатывания, попадания, команда.
- **Командный пункт** — захват базы, противостояние, аптечка: сила и интервал выброса, выстрелы для захвата, время раунда, самовосстановление, интервал и команды.

Полное дерево меню с диапазонами значений: [docs/menu.md](docs/menu.md).

Заводские функции пульта не меняются. В разделе «Информация» версия показывается как «v1.14-mod».

## Как собрать прошивку

Нужен Python 3.10 или новее (https://www.python.org/downloads/), больше ничего устанавливать не надо.

1. Скачайте этот репозиторий: кнопка **Code → Download ZIP**, распакуйте.
2. Скачайте официальную прошивку v1.14: https://laserwar.ru/admin/uploads/adminFiles/Smart_PRO_Remote_v1_14.zip и положите zip в папку репозитория. Распаковывать не нужно.
3. Откройте в этой папке командную строку и выполните:

```
python build.py Smart_PRO_Remote_v1_14.zip
```

Появится файл `Smart_PRO_Remote_v1.14_mod_1.04.bin`. Перед записью скрипт сам проверяет новое меню, это занимает около минуты. Ключ `--quick` пропускает проверку.

Скрипт принимает только официальный файл v1.14: если прошивка другая или файл повреждён, сборка остановится.

## Как прошить пульт

1. Переведите пульт в режим обновления (кнопки Down + ESC, как при обычном обновлении прошивки Laserwar) и подключите к компьютеру по USB. Пульт появится как USB-диск.
2. Скопируйте `.bin` в корень диска.
3. Дождитесь перезагрузки пульта. В главном меню появится пункт «Девайсы».

Вернуть официальную прошивку можно так же, скопировав официальный `.bin`.

## Отказ от ответственности

Проект неофициальный и не связан с компанией Laserwar. Прошивка распространяется бесплатно и без каких-либо гарантий, установка — на ваш страх и риск. Официальная прошивка и торговая марка Laserwar принадлежат правообладателю; в репозитории их файлов нет, сборка делается из официального файла, который вы скачиваете сами.
